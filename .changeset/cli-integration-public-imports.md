[feat] `astryx doctor integration validate` now warns, from source and without a build, when what an integration package tells apps to import cannot be imported, so `astryx integration check --strict` fails on it. Each is a warning, so `doctor integration validate` and a plain `integration check` keep their exit codes. It warns on a component doc's `import` or a template's public import whose subpath package.json `exports` does not declare (a missing key, a key whose only conditions an ES module import does not load, such as `require` or `types`, an `exports` that is a single string, a wildcard that does not match) or that names another package; a component example that imports a subpath the package does not declare or a name it does not export; a template source with no default export (`astryx template` still copies it, but its public import and anything that renders it get nothing); a template that imports a relative path outside the templates root, a path its own package or Core does not export, or a name its package does not export; and a block whose `exampleFor` or `componentsUsed` names no component of the package or Core and is not imported by the template (Core's names are not judged when Core is not installed). Each warning names the fix, such as the exact `exports` entry to add. Only the declared subpath is judged, never the target file, so `exports` may point at build output that does not exist yet; wildcards and condition objects with `import` or `default` pass, a package with no `exports` keeps its deep paths to files it ships, and a CommonJS module is not judged for the names it exports.

`astryx integration add component` and `astryx integration add template` still add the new subpath to an `exports` map the package already has, and still create none. When that entry is the only change to package.json, it is now inserted alone and every other byte of the file stays as it was; a subpath a wildcard such as `./components/*` already covers is no longer added. When `files` also changes, package.json is still rewritten whole, as before.
